# Contribuição

## Fluxo recomendado

1. Crie uma branch curta a partir da branch principal.
2. Faça alterações pequenas e focadas.
3. Execute `bun run typecheck` e `bun run build`.
4. Revise se nenhum segredo ou arquivo `.env` entrou no commit.
5. Abra um pull request descrevendo a mudança e como ela foi validada.

Evite reescrever o histórico já publicado, pois o projeto pode permanecer
sincronizado com a Lovable.
